        Import a local document

        TXT, Markdown, CSV, DOCX or text-based PDF · maximum 4 MiB. Extraction stays local and never executes embedded content. PDF support requires the optional pypdf dependency.

          Typed reference assertions

          Each field is graded independently. Numeric tolerance is absolute; booleans require true/false and strings use trimmed, case-insensitive comparison. Reference values are never added to the model request schema.

          Adversarial attachment and objective

          Unchecked attachments are unapproved external documents. Approval authenticates provenance; it does not establish truth or make their instructions safe.
